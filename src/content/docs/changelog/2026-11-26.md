Volt 1.1.0 brings the mobile client to installer-managed hotels. Atom Nuxt 1.0.0 lets players add the hotel to their home screen. PlusEMU 1.0.42 fixes dance checks in Wired. Volt 1.0.20 restores missing icons, and Volt Renderer 1.0.10 fixes how avatars appear when they lie down.

## Play on a phone

- **Rooms and chat.** The toolbar sits at the bottom in portrait and groups the controls in the lower left in landscape. Tap the speech bubble to chat. You can close it to see the room and reopen it to finish your draft. Chat history opens in its own panel.
- **Shop and inventory.** Tap furniture in a room and choose **Buy** to close its action panel and open the matching offer. You can keep browsing while the preview and price stay below the grid in portrait or beside it in landscape. Inventory uses the same layout. The inventory filter and furniture rotation controls use arrows that match their buttons. When placing an item, you can rotate it or cancel from the room.
- **Find a room.** Tap a room's info button to see its details. The Navigator puts search and room actions beside the results in landscape, so more rooms fit on screen.
- **Other windows.** Friends, Messenger, profiles and the avatar editor have touch layouts. There are also phone controls for quests, daily tasks, the reward track, the floor plan editor and Wired tools.
- **Home screen app.** The Atom Nuxt website lets visitors add the hotel to their home screen. The install banner keeps its button text on one line on small phones. The game adjusts when the phone rotates or the keyboard opens. If the hotel cannot be reached, the app shows an offline page.

[See the portrait and landscape screenshots](https://plusemu.dev/showcase/mobile-layout.html) or download [Volt 1.1.0](https://github.com/plus-emulator/Volt/releases/tag/v1.1.0) and [Atom Nuxt 1.0.0](https://github.com/atom-projects/atom-nuxt/releases/tag/v1.0.0).

## Released fixes

- **PlusEMU 1.0.42.** Wired dance checks and `@dance` now report the right dance after a player uses `:dance` or an effect stops the dance. [PlusEMU release](https://github.com/plus-emulator/PlusEMU/releases/tag/v1.0.42)
- **Volt 1.0.20.** Effect icons appear in the catalog and purchase notices. Reward Track icons start loading as soon as the client opens. AIR buttons keep their borders and disabled appearance when a window opens. Closing a Wired menu while its font loads no longer causes a late update if the font fails. [Volt release](https://github.com/plus-emulator/Volt/releases/tag/v1.0.20)
- **Volt Renderer 1.0.10.** An avatar changes pose and position together when lying down or switching sides of a bed. The renderer avoids duplicate avatar downloads and finishes loading built-in room backgrounds and required dance effects before the first room opens. [Volt Renderer release](https://github.com/plus-emulator/Volt-Renderer/releases/tag/v1.0.10)

The three projects also moved their automated checks to their own build machines.

## Installer 2.5.0 and Atom CMS 1.6.1

- **Windows installer.** Setup can set folder permissions on non-English Windows installations, including French Windows. [Windows installer fix](https://github.com/plus-emulator/plusemu-installer/pull/26)
- **Linux installer.** Setup connects the website to the hotel's camera service for avatar images when both support it. Hotels keep any custom avatar image address they already use. [Avatar image setup](https://github.com/plus-emulator/plusemu-installer/pull/31)
- **Atom CMS.** **Download logo** and **Use logo** work again in both the Atom and Dusk themes. A failed upload now shows an error. [Logo generator fix](https://github.com/atom-projects/atom-cms/pull/294)
- **Atom CMS dependencies.** The website updated its frontend and PHP packages, including security fixes for Symfony and League CSV. The Docker configuration now uses MariaDB 12.3.3 and Redis 8.10.3. The development setup also updates Mailpit for testing email and the GitHub Actions used for automated checks. If you update the website from source, run `php artisan migrate --force` in the Atom CMS directory to move existing activity log entries to the new format. [Atom CMS changes since 1.6.0](https://github.com/atom-projects/atom-cms/compare/v1.6.0...v1.6.1)

## Update your hotel

For an installer-managed hotel, run `sudo plusemu-update` on Linux or `plusemu-update` in Administrator PowerShell on Windows. This installs the released emulator and mobile client. Update Atom CMS and the Atom Nuxt website separately. [Hotel update guide](/getting-started/updates/)
