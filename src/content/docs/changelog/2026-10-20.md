**Versions:** PlusEMU 1.0.2 to 1.0.19, Volt 3.5.1, Volt Renderer 2.1.0, installer 1.4.0 to 1.6.0.

Most of the work went into WIRED v2 again. There is also a new Collectibles hub, pet companions, room backgrounds, and an installer that can now update your hotel for you.

## Highlights
- **Collectibles hub.** The Collectibles entry in the Me menu now works. It has the Collection, Shop and Relics tabs with Habbo's sets, shop offers, mint token packs and mintable furni. See [Collectibles](/features/collectibles/).
- **Avatar collectibles and pet companions.** Players can wear avatar collectibles, and the 33 pet companions are sold on a new Clothing > Companions page. See [Pet companions](/features/pet-companions/).
- **Latest Habbo AIR build.** Packets match AIR `WIN63-202610201032-107964540`, so the official AIR client can still connect.
- **Lots of WIRED v2 fixes.** Editor saves, timing, variables, selectors, chests, bots and games were all compared side by side with real Habbo.
- **One-command hotel updates.** `plusemu-update` updates PlusEMU, Volt and the hotel files on Linux and Windows, with a backup and automatic rollback.
- **One-command PHP security updates** for any hotel, also ones not made by the installer.

## PlusEMU 1.0.2 to 1.0.19

### WIRED v2
- Editor saves are stored the way Habbo stores them, for many more boxes. This includes Control Clock, bot actions, chests, pointers, share and import, Match to Snapshot, Users With Variable, habbicon variables, give score limits and the transaction editor.
- Odd or broken editor saves are fixed or refused the same way Habbo does it.
- Each box's save rule now lives in one place, which makes new boxes easier to add.
- Habbo's own Wired room settings messages are answered, so the official client can open and save them.
- Room Initialized runs once when the room loads, so its effects are already there for the first visitor.
- Variable Changed, Score Achieved and other event triggers run in the same tick as the change.
- The room timer starts at load. Reset Timers restarts repeaters on the next room tick.
- Game timers cycle and keep their saved duration. Game counters keep counting.
- Moves, rotations, projectiles and clock changes that fire in one tick are sent together in one update, like on Habbo.
- Furni to User can land on the door tile. Follow picks a random tile around the user. Chase picks a random user when targets tie. Flee works like Habbo.
- Selected users are picked in a random order, like Habbo.
- Pointers resolve, and shared variable add-ons stay in sync.
- Variable box flashes, level effects, Variable FX, leaderboards and hand items match Habbo.
- Has Altitude, Has Variable, Match Date and time checks match Habbo.
- Signal loops that toggle furni stay in one tick. Signal stack messages show after the echo of a say.
- Toggle State targets, turn packets, source errors and snapshot text match Habbo.
- Furni highlight and visibility, flag furni and the Wired glowball (two states) work like Habbo.
- The freeze effect stays on when you join or leave a team. The right effect comes back when a teleport ends a freeze. The teleport glow ends at the right moment.
- Chests refuse to give items to users who cannot trade. Kick User and the variable reference match Habbo.
- Sleep ends after 2 seconds, like Habbo.
- The Wired Disabler sends a data update when used. Only one chooser disabler is allowed per room.
- Unreleased Wired boxes moved to a staff-only catalogue page. Before, any player could buy them, including one that hands out any achievement.
- The nine Wired boxes Habbo now sells are in the catalogue with Habbo's offers, order and prices.

### Collectibles and avatars
- New Collectibles hub: wallets, collections, shop offers, minting, transfers and monthly reward claims, all saved in the database.
- Habbo's collectible sets, shop offers, mint token packs and mintable furni are included, so a new hotel has content right away.
- Avatar collectibles. Staff can give one with `:givecollectible <username> [avatar|clothes|genesis]`.
- Pet companions are sold for 25 credits on a new Clothing > Companions page.
- Avatar effects are worn, cleared and expire like on Habbo. See [Avatar effects](/features/avatar-effects/).
- Avatar heads turn toward a user or bot that speaks.

### Rooms and furni
- Room background settings are checked. Numbers are limited, and you can limit image websites with `room.background.allowed_hosts`. Users with security level 4 and higher can save them, like on AIR.
- Saving a room background keeps its rotation.
- Effect boxes open like on Habbo, and boxes stuck in the opening state are closed.
- Team gates, scores and locks, the room configuration furni, the clicker and switches match Habbo.
- Signs show for one update, like Habbo.
- Given rights stay in group home rooms.
- No extra avatar update when moved furni still covers the avatar.

### Protocol and other fixes
- Header ids match AIR `WIN63-202610201032-107964540`.
- The login sends Habbo's 12 user perks in Habbo's order. Camera perks follow the camera permission.
- Friendships are counted once on profiles.
- The `givecollectible` permission is registered.

## Installer 1.4.0 to 1.6.0

- **New:** `plusemu-update` updates PlusEMU, Volt and the hotel files with one command, on Linux and Windows. It backs up the hotel first and restores the backup if a step fails. See [Update PlusEMU](/getting-started/updates/).
- **New:** `plusemu-update --assets` adds the stock hotel files you are missing, without stopping the emulator. Files you already have stay as they are.
- **New:** `php-update.sh` (Linux) and `php-update.ps1` (Windows) update PHP to the newest security release of the same version, for example 8.5.11 to 8.5.12. They work on any hotel, also ones not made by the installer.
- The hotel files pack is now complete. It adds 286 files the old pack was missing, like quest images, furniture, effects, daily task images, sounds and the habbicons sprites.
- Running the installer again now refreshes the hotel files when a newer pack exists.
- Fixed the Windows one-line install, which stopped right away with a "GuideMode" error.
- IIS now serves `.ogg`, `.webp` and `.json` hotel files.
