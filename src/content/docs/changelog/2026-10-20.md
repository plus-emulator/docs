**Versions:** PlusEMU 1.0.2 to 1.0.23, Volt 3.5.1, Volt Renderer 2.1.0, installer 1.4.0 to 1.7.0.

Most of the work went into WIRED v2 again. There is also a new Collectibles hub, pet companions, room backgrounds, and an installer that can now update your hotel for you.

## Highlights
- **Collectibles hub.** The Collectibles entry in the Me menu now works. It has the Collection, Shop and Relics tabs with Habbo's sets, shop offers, mint token packs and mintable furni. Since 22 October the hub uses Emeralds only, and a shop offer can need a collector level. See [Collectibles](/features/collectibles/).
- **Avatar collectibles and pet companions.** Players can wear avatar collectibles, and the 33 pet companions are sold on a new Clothing > Companions page. See [Pet companions](/features/pet-companions/).
- **Latest Habbo AIR build.** Packets match AIR `WIN63-202610201032-107964540`, so the official AIR client can still connect.
- **Lots of WIRED v2 fixes.** Editor saves, timing, variables, selectors, chests, bots and games were all compared side by side with real Habbo.
- **One-command hotel updates.** `plusemu-update` updates PlusEMU, Volt and the hotel files on Linux and Windows, with a backup and automatic rollback.
- **One-command PHP security updates** for any hotel, also ones not made by the installer.
- **Planned shutdown alerts.** Before a planned shutdown, every player gets Habbo's maintenance alert. See [Planned shutdowns](#planned-shutdowns).
- **Hotel-wide staff effect.** You can now turn off the Habbo Staff badge for the whole hotel. See [Avatar effects](/features/avatar-effects/).
- **Safer purchases and trades.** Wallet changes, furni, effects and badges are saved together with the payment, and untradeable furni can no longer be traded.

## Before you update

- Update PlusEMU, Volt and Volt Renderer together. The Collectibles shop offers and the SnowStorm game messages changed, and the three must match.
- PlusEMU 1.0.20 and later run migration 113 when they start. It converts the Collectibles hub to Emeralds. PlusEMU writes a backup first. See [database migrations](/getting-started/migrations/).

## PlusEMU 1.0.2 to 1.0.23

### WIRED v2
- Editor saves are stored the way Habbo stores them, for many more boxes. This includes Control Clock, bot actions, chests, pointers, share and import, Match to Snapshot, Users With Variable, habbicon variables, give score limits and the transaction editor.
- Odd or broken editor saves are fixed or refused the same way Habbo does it.
- Each box's save rule now lives in one place, which makes new boxes easier to add.
- Habbo's own Wired room settings messages are answered, so the official client can open and save them.
- Room Initialized runs once when the room loads, so its effects are already there for the first visitor.
- Variable Changed, Score Achieved and other event triggers run in the same tick as the change.
- The room timer starts at load. Reset Timers restarts repeaters on the next room tick.
- Game timers cycle and keep their saved duration. Game counters keep counting.
- Moves, rotations, projectiles and clock changes that fire in one tick are sent together in one update, like on Habbo.
- Furni to User can land on the door tile. Follow picks a random tile around the user. Chase picks a random user when targets tie. Flee works like Habbo.
- Selected users are picked in a random order, like Habbo.
- Pointers resolve, and shared variable add-ons stay in sync.
- Variable box flashes, level effects, Variable FX, leaderboards and hand items match Habbo.
- Has Altitude, Has Variable, Match Date and time checks match Habbo.
- Signal loops that toggle furni stay in one tick. Signal stack messages show after the echo of a say.
- Toggle State targets, turn packets, source errors and snapshot text match Habbo.
- Furni highlight and visibility, flag furni and the Wired glowball (two states) work like Habbo.
- The freeze effect stays on when you join or leave a team. The right effect comes back when a teleport ends a freeze. The teleport glow ends at the right moment.
- Chests refuse to give items to users who cannot trade. Kick User and the variable reference match Habbo.
- Sleep ends after 2 seconds, like Habbo.
- The Wired Disabler sends a data update when used. Only one chooser disabler is allowed per room.
- Unreleased Wired boxes moved to a staff-only catalogue page. Before, any player could buy them, including one that hands out any achievement.
- The nine Wired boxes Habbo now sells are in the catalogue with Habbo's offers, order and prices.
- Wired ticks run on the room's 500 ms grid. One tick is sent as one data update and one movement update.
- Pick lists reopen in the same order as on Habbo, and a save with more than 20 picks is dropped, as on Habbo. Unknown picks are dropped instead of refusing the whole save.
- Add-ons and variable boxes accept at most 20 picks. Give, Change and Remove Variable save on any variable id, also with empty slots, and work with pointers in a delay.
- Same-holder saves work on a global value match and on three more boxes. Same-holder references are paired at random.
- Context variables and `@state`, `@handitem` and `@occupation` behave like Habbo. Writes to `@state` on Wired boxes are ignored.
- Variable boxes send their variable info in the editor. A reference to a variable whose source was picked up stays in the list until the room unloads.
- Text connectors use a fallback line, limit the text by bytes, and show the fallback in leaderboard rows. A leaderboard updates after you save a connector on its tile.
- Text-mode capturers capture labels only, and nothing without a connector.
- Show Message sorts placeholder and capturer names, and allows at most forty lines in thirty seconds.
- Toggle to Random only changes furni that the hotel can change. At Given Time counts from the last reset, not from the save.
- Give and Change run after Toggle State, Move, User to Furni and Furni to User. Remove Variable runs after Give Variable in one stack.
- Furni Clicked stacks run at the click and send one flash packet. A click sends its toggled states before the turn of the user.
- Match to Snapshot stacks furni in a random order. Snapshot moves that only change the position are sent in one packet.
- Movement Curve saves are clamped instead of refused. The projectile curve wins over the Movement Curve add-on.
- Bot Move to the bot's own tile sends nothing. Heads turn toward a bot that says a Show Message.
- Users who join a Banzai, Freeze or game gate team get the team chat bubble.
- Fresh Variable Age, Variable Changed, move and snapshot boxes save correctly. Variable names are cleaned, and invalid Text Output Username names are refused.
- Furni to User stays under a walking user. A standing user is carried on a restacked walk magic tile.
- Wired blobs are set on the room tick, and reset buttons reset after 600 ms.

### Collectibles and avatars
- New Collectibles hub: wallets, collections, shop offers, minting and monthly reward claims, all saved in the database.
- The hub uses Emeralds only. Relics cost Emeralds, the Transfer tab and linked wallets are gone, and a shop offer can need a collector level (`collectible_shop_offers.min_level`). Migration 113 converts existing hotels at startup. Use Volt and Volt Renderer from the same time, because the shop offer message changed.
- Habbo's collectible sets, shop offers, mint token packs and mintable furni are included, so a new hotel has content right away.
- Avatar collectibles. Staff can give one with `:givecollectible <username> [avatar|clothes|genesis]`.
- Pet companions are sold for 25 credits on a new Clothing > Companions page.
- Tired pets refuse commands and gain no experience at any level. Before, pets above level 15 obeyed without energy.
- The hotel-wide setting `room.forced_effect.staff` sets the effect staff get in a room. Set it to `0` to turn the Habbo Staff badge off for everyone. `room.forced_effect.ambassador` does the same for ambassadors. See [Avatar effects](/features/avatar-effects/).
- Avatar effects are worn, cleared and expire like on Habbo. See [Avatar effects](/features/avatar-effects/).
- Avatar heads turn toward a user or bot that speaks.

### Rooms and furni
- Room background settings are checked. Numbers are limited, and you can limit image websites with `room.background.allowed_hosts`. Users with security level 4 and higher can save them, like on AIR.
- Saving a room background keeps its rotation.
- Effect boxes open like on Habbo, and boxes stuck in the opening state are closed.
- Team gates, scores and locks, the room configuration furni, the clicker and switches match Habbo.
- Signs show for one update, like Habbo.
- Given rights stay in group home rooms.
- No extra avatar update when moved furni still covers the avatar.
- Builders Club places the Payment, Trade and Reward contracts, keeps the poster number on posters, starts a placed multi-state wall item at state 0, and counts new furni in its placement count. It sends the furni count before the floor furni add and remove.
- Picking up furni sends the picked up furni, not a full inventory reload.
- Blocks get their state heights, game state furni get Habbo's usage and start state, the theater light has three states, and the super blob stays usable.
- A flag furni sends a data update when it is used.
- Football and puck move only on real kicks. Freeze hits count only while the game runs. Banzai fills only the tiles that a team's own locks enclose, so L-shaped loops fill.
- Users without Habbo Club no longer send club expressions and dances to the room.
- A bot stands on top of the furni under it, keeps its decimal height when the room reloads, and greets with a random line of three when you place it.
- Avatars that sleep wake on the next room tick. A diagonal floor sit turns one step clockwise. A second user update follows a roller slide.
- A click with no route is ignored while the user walks, and a walk continues on a click over a height step.
- A crashed room unloads without blocking the other rooms. Before, one crashed room could freeze the whole hotel.

### Planned shutdowns
- The console command `shutdown <minutes> [duration]` and the RCON command `shutdown` send Habbo's maintenance alert to every user. They send it again at one minute left, and then shut the server down.
- While a shutdown is planned, PlusEMU refuses furniture, gift, Habbo Club and Builders Club purchases and new trades. Volt hides the trade button.

### Catalogue, trading and safety
- Marketplace purchases, sold-offer claims and vouchers save the wallet in the same transaction. A voucher that the wallet cannot hold stays unused.
- Furni, effects and badges are created inside the payment. A failed delivery no longer takes the credits or an LTD serial.
- Trade offers refuse furni that cannot be traded. Bulk offers follow the same limits as single offers: 500 items and 9 LTD items.
- The ban cache uses the ban type and the value, so a ban on one type does not hide another.
- Private message logging finishes before the send flow continues. A failing logout task no longer stops the disconnect.
- The navigator lists public rooms from `navigator_publics` on the Public tab. A room without `image_url` shows its normal thumbnail.
- `:ha` and `:hal` send the alerts that AIR shows. `:hal <link> <message>` adds a "More information" link.

### Protocol and other fixes
- Header ids match AIR `WIN63-202610201032-107964540`. SnowStorm messages now use their official AIR ids, so a SnowStorm match can run on Habbo's AIR client. Update the client with PlusEMU.
- The login sends Habbo's 12 user perks in Habbo's order. Camera perks follow the camera permission.
- Friendships are counted once on profiles.
- The `givecollectible` permission is registered.

## Installer 1.4.0 to 1.7.0

- **New:** `plusemu-update` updates PlusEMU, Volt and the hotel files with one command, on Linux and Windows. It backs up the hotel first and restores the backup if a step fails. See [Update PlusEMU](/getting-started/updates/).
- **New (1.7.0):** `plusemu-update` adds the new settings that a Volt release ships. It reads `ui-config.example` and `renderer-config.json.example.json` from the release, adds the settings your hotel lacks, and keeps every value you already set.
- **Fixed on Windows (1.7.0):** an update no longer breaks the emulator folder when a program still uses it. The updater ends a leftover `shawl.exe`, names any other program that still runs from the folder, retries locked moves, and never deletes a folder it cannot replace.
- **New:** `plusemu-update --assets` adds the stock hotel files you are missing, without stopping the emulator. Files you already have stay as they are.
- **New:** `php-update.sh` (Linux) and `php-update.ps1` (Windows) update PHP to the newest security release of the same version, for example 8.5.11 to 8.5.12. They work on any hotel, also ones not made by the installer.
- The hotel files pack is now complete. It adds 286 files the old pack was missing, like quest images, furniture, effects, daily task images, sounds and the habbicons sprites.
- Running the installer again now refreshes the hotel files when a newer pack exists.
- Fixed the Windows one-line install, which stopped right away with a "GuideMode" error.
- IIS now serves `.ogg`, `.webp` and `.json` hotel files.
