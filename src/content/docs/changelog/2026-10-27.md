**Versions:** PlusEMU 1.0.25, Volt 3.5.1 (`83b02ae`), Volt Renderer 2.1.0 (`c203a72`).

## Highlights

- **Latest Habbo AIR build.** Packets match AIR `WIN63-202610271147-806594867`, so the official AIR client can still connect.
- **Wired Creator Tools like AIR.** The `:wired` tabs and windows now look and work like the official AIR client, and they use Habbo's own packets.
- **Chest transaction log.** The Chests tab lists the room's recent transactions, with a detailed list window.
- **Reload and Rollback buttons work.** In your room, type `:wired` and open the Settings tab. Reload sends everyone out of the room and back in. Rollback puts all furni back where they were when the room loaded. Before, both buttons did nothing.
- **Account level.** Every account has a level. It also sets the room's Wired execution cost limit.
- **Rollers like Habbo.** Riders, cargo and moved furni roll with Habbo's timing and heights.
- **Furniture states.** More than 300 furniture classes now have Habbo's state count, so a double-click or Toggle State cycles like Habbo.
- **Lots of WIRED fixes.** Pointers, variables, Text Output, bots, leaderboards and games were all compared side by side with real Habbo.

## Before you update

- Update PlusEMU, Volt and Volt Renderer together. The new AIR build changed the numbers of the network messages, so an old client cannot talk to a new server.
- PlusEMU 1.0.25 runs migrations 121 to 130 when it starts. They add the chest transaction log, the Wired account preferences, the chat preferences and the account level, and they fix furniture state counts. Rooms that already exist keep their Wired edit rights. PlusEMU writes a backup first. See [database migrations](/getting-started/migrations/).

## PlusEMU 1.0.25

### WIRED

- Users now move with a furni that Wired raises or lowers under them, in the same packet.
- Wired can raise or turn a furni that a user stands on, also when the furni moved onto the user earlier in the same firing.
- A user with rights who uses a Wired antenna sends its signal. Receive Signal runs with that user as the triggering user.
- An unsaved `Text Output (variable)` add-on no longer stops its stack. The stack runs, and the placeholder stays as written.
- A Give, Change or Remove Variable with a precise delay, for example 50 ms, now writes through its pointer.
- A Give Variable into a context variable from several furni takes the value of a random one of them each time.
- A split signal flips a context box once per click, not twice.
- Call Stacks starts the called stack with an empty context, and the called stack no longer flashes its selectors.
- Filter add-ons keep nothing when their amount variable has no value.
- Variable names and pointer names are cleaned before the 40 character check. A pointer cannot use an echo of a context variable.
- Variables without a value print `null`, list no last update time, and send `-1` or `null` in Send Dataframe rows.
- Send Dataframe in variable text mode on a pointer sends the Text Connector label of the pointed variable.
- Give Variable with "override existing" creates `@can_move_freely` again. Change Variable Value never creates it.
- Place Furni "spawn with variable" gives the copy its variable in any stack.
- Echo variables are listed as normal variables, and Variable Changed fires when the mirrored variable changes.
- Built-in variables like `~clock`, `~chest`, `~area_hide`, `~recolorable_furni` and `~teleport` show only in rooms with that kind of furni.
- `Text Output (variable)` prints a bot's value. `Text Output (furni name)` with Show Multiple on prints empty text when nothing is picked.
- Leaderboards offer only the user variables on their tile, and they refresh in the right order when another board is saved or picked up.
- Sit and Stand triggers fire with the status update on the next room tick.
- User Performs Action follows the real sleep state. Respect counts for 2 seconds, and a later expression ends a wave or respect.
- A whisper fires Says Something. A whisper to a name that is not in the room is shown to the speaker.
- Adjust Clock runs an Increase before a Decrease in one stack, and resends the value every time.
- All Repeat and Repeat Long triggers of a room tick on one room timer.
- A game counter start puts every blob it does not select back to state 0.
- A Wired round writes all five high score board kinds for every team.
- Bot Follow starts and aims like Habbo, so the bot no longer stops 2 tiles away and waits.
- With No Move Animation, a furni that Wired moves several times in one firing jumps straight to its final place. A trigger box that Wired moves no longer stays lit after it flashes.
- The server sends fewer status updates for a user that Wired moves. The Wired status now ends with the move animation.
- Curved Wired moves use only Habbo's own movement message. The extra message that PlusEMU sent before each move is gone.
- The Wired UI style can be up to 30,000 characters long.
- In a room with no saved Wired settings, only group admins can edit Wired.

### Wired Creator Tools

Type `:wired` in your own room to open the Wired Creator Tools.

- The Reload and Rollback buttons on the Settings tab now work. Before, they did nothing.
  - **Reload** reloads the room. Everyone in it is sent out and comes back in 2 seconds later.
  - **Rollback** puts every furni back to the place and state it had when the room loaded. It asks you to confirm first. Only the room owner or staff can use it.
- The Chests tab shows the room's transaction log: manual, Wired, contract payment, contract reward and contract trade.
- The Variables tab buttons use Habbo's packets. Highlight lists the holders, Manage pages and edits permanent user variables, and Delete clears all holders.
- The Wired account preferences (toolbar button, inspect button, playtest, whisper, notifications and style) are saved on the account.
- Dates in Variable Management and Wired Logs show as `28-10-2026`, like Habbo.

### Rollers

- A rider gets a status at every roller of a fast chain, and lands on the top of the next roller.
- A rolled user lands at the right height, and a roller can slide a user onto the door tile.
- All cargo of one roller slides in one packet, and in a room without Wired, cargo that floats up to 0.6 above the roller is carried.
- A user on rolling furni slides together with it.
- Furni that a user or Wired moves onto a roller, and a roller that is moved under a user, wait one room tick first.
- Rollers show state 1 and ignore a double-click.

### Avatars, chat and accounts

- Every account has a level that the profile, `@level` and User Level read. A room's Wired execution cost limit is 312.5 x (owner level + 2). Every account starts at level 8, so existing rooms keep their limit of 3125.
- Chat mode, bubble width, scroll speed, online indicator and chat size are saved per account.
- Any expression ends a dance first, like Habbo.
- Sit and Stand apply on the next room tick. A sit while walking is kept until the walk ends.
- A click on a tile you cannot reach no longer sends an extra status update.

### Furniture

- Habbo's state counts for more than 300 furniture classes, so a double-click and Toggle State cycle through the right states.
- Vending machines hand over the item after 1250 ms and go back to 0 at 1500 ms. Nine more classes use the vending machine interaction, and five more classes give Habbo's hand item.
- High score boards open when you use them.
- Gates, recolorable stairs and floor switches answer a click like Habbo. A click on a far floor switch walks to it first.

### Staff

- `:stress players` adds test players for room load tests. Only hotel owners can use it, in private rooms. It is limited and cleans up when you leave.

## Volt 3.5.1 (83b02ae) and Volt Renderer 2.1.0 (c203a72)

### New

- The Wired Creator Tools (`:wired`) now look like the AIR client: the Variables, Monitor, Settings, Chests and Inspection tabs, the header, the Variable Management, Wired Logs, Transaction logs and Wired Error Information windows.
- The Monitor tab shows Habbo's error rows and statistics, and Clear all works.
- The Inspection tab has the "W" button. It highlights the Wired boxes that pick the selected furni.
- Playtest mode notices and the `:playtest` command, like the official client.
- High score boards open as the AIR bubble above the furni.

### Fixes

- The client uses the network message numbers of AIR `WIN63-202610271147-806594867`, the same as the server.
- Variable pickers, like the Pointer accessor list, are no longer empty in rooms with more than 100 variables.
- Triggerer Matches keeps the user source you chose after a save.
- Set Visibility also hides the avatar's shadow, effects and variable FX.
- The inventory chest icon counts only inventory items.
- Drop-down menus, like the timezone list and the menus in the catalogue marketplace, look like AIR.
