**Versions:** PlusEMU v2026.10.19-975399e, 1.0.0 and 1.0.1, Volt 3.5.0 (build b8ad350), Volt Renderer 2.1.0 (build 768cac9), installer 1.3.0.

PlusEMU now has semantic version numbers, starting at 1.0.0. The emulator also updates its own database at startup, and most of the other work went into WIRED, room entry and the client look.

## Highlights
- **Automatic database migrations.** The emulator applies the database updates it is missing every time it starts, after it makes a backup. You no longer run SQL files by hand.
- **Semantic versions.** Releases are now numbered 1.0.0, 1.0.1 and so on, instead of a date and a commit.
- **Daily tasks.** The daily tasks window works. Players get tasks and can claim their rewards.
- **Walking like on Habbo.** Avatars find and fix their path with the same rules as on Habbo, in every room.
- **Room entry like on AIR.** The server sends the room right after it opens, in Habbo's order, and Teleport to Room switches rooms on the server.
- **Many WIRED fixes.** Movement, timing, freeze, bots, selectors, variables and temporary furni were compared with real Habbo.

## PlusEMU v2026.10.19-975399e, 1.0.0 and 1.0.1

### For hotel owners
- The emulator applies missing database migrations at startup. It records each one in a new `schema_migrations` table. An empty database gets a fresh install.
- Before it changes anything, the emulator writes a full database backup to the `backups/` folder. If the backup or a migration fails, the emulator stops and logs the file and the statement.
- Older hotels are detected, so migrations you already ran by hand are not run twice.
- New start options: `--migrate-status` shows the state, `--migrate` applies the migrations and exits. `--migrate-mark-applied <file>` and `--migrate-allow-gaps` help when a database is in an unclear state. Set the new config key `Database.Migrations.AutoMigrate` to `false` to stop the emulator from starting while migrations are pending.
- Releases use semantic versions, starting at `v1.0.0`. Older tags and download file names stay the same.
- A chat command that fails no longer disconnects the player. The player gets a whisper that shows how to use the command, and the error is still logged.
- `:emptyitems yes` no longer fails when the inventory holds a Wired chest. The chest and its furni are deleted, and its coins go back to the player as credits.
- `:pickallbc` works again, because its permission is now registered.
- `:stress bots` spawns up to 2000 bots with random outfits. Only the owner role can run it now.

### Rooms
- The server sends the room data as soon as the room opens. The client no longer has to ask, and a second request no longer removes the user from the room.
- Room entry packets go out in Habbo's order. The entering user's status and user entry are sent once.
- Heights are written like on Habbo, for example `1.0` instead of `1`. The height map update uses Habbo's id 853.
- Our own furni data message is no longer sent to the official AIR client, which does not know it.
- Floor items send Habbo's usage policy, so the Use button works like on Habbo for fridges, Floor Switches, score boards and game counters. Seats send their sit status like on Habbo.
- Avatar rights are cleared when a user in the room loses them.
- A refused furni move shows the placement error. A room with a leaderboard unloads without a crash.
- Room backgrounds can be saved with normal web image addresses. Unsafe addresses are still refused.

### Walking
- Walking follows Habbo's rules: a fixed step budget from the click, remembered furni, a new path only when a step is blocked, and standing avatars as a path cost. Every room uses the same pathfinder.

### Furni, pets and chests
- The football gate saves and applies a look for both genders. The Wheel of Fortune can be placed and spun. The Glass Door has Habbo's two states.
- Players can claim the free cursed dragon pet.
- The server answers the avatar collectibles request from the avatar editor.
- Chests refuse deposits from users who cannot trade. A moved chest is no longer locked again.
- Club gifts show the HC icon, and club tenure is sent like on Habbo.

### Daily tasks and chat
- Daily tasks are new. The server sends the tasks and players can claim them.
- System chat styles, like parrot and santa, are staff-only again, like on AIR. A migration runs at startup for this.
- Chat packets no longer end with an unset "hide username" flag, like on Habbo.

### WIRED movement and timing
- Move/Rotate lands furni on stackable furni instead of stopping. With no move and no turn, it restacks its furni.
- When one furni in a group is blocked, the rest of the group still moves. Group moves are listed in pick order.
- Wired furni moves meet users on the tile their step goes to.
- Chase follows users in its row or column and never turns straight back.
- Delayed effects and timed steps run at their due time, also in busy rooms.
- A Fast Queue pulse stays in one frame when another stack shows a message.
- User Stuff Collision runs in the pulse that raised it.
- Signal loops run up to 100 times per stack.
- Running game counters restart on Start. Score Achieved fires once per game round. A user who leaves all teams is told that it is no longer playing.

### WIRED freeze, teleport and bots
- A user frozen in the middle of a walk finishes the step that was already announced. Freeze and unfreeze effects are sent on the next room tick.
- Teleport to Room shows the teleport glow first and then switches the room on the server, like on Habbo. Enter Room stacks run inside the room entry.
- Bot Give Handitem walks the item over to the user. The bot keeps the item when it cannot reach the user, and the walk ends when the user leaves.
- Bot Clothes stores outfits like on Habbo. A placed bot keeps its motto and gender, faces direction 2 and lists its ten skills.

### WIRED messages
- A speech stack flashes before its effects send anything. Chat comes after the flash, and other effects send at once.
- A hidden chat is echoed to the speaker after the stack's flash.
- Chest gives no longer fire Transaction Failed, and players see the failure dialog.
- A gate's Toggle State is sent together with the other Wired data.

### WIRED selectors
- Users By Name matches names exactly. Users With Handitem selects only users and saves any item code.
- Users In Group selects every member of the group.
- Area selectors limit out-of-range bounds instead of refusing the save.
- Furni selectors and Furni From Signal can select Wired boxes. Type selectors include wall furni.
- A stepping user is selected on the tile the step goes to.
- Remote Selection can be nested with no depth limit. Empty selections are skipped when signals are split.
- Exact speech matching keeps spaces.

### WIRED variables
- New variable slots start at "0", and variables without a value read as -1, like on Habbo.
- Divide and modulo by zero and random numbers work like on Habbo.
- `@rotation` and the rotation in `@occupation` use the furni's own directions.
- Builders Club furni read `@type` as 1 and refuse colour writes.
- Users only show the built-in variables their avatar has.
- Context variables have their time parts, like `.value.year`.
- Variable Changed saves with no change types. Variable definitions show the decrease state and flash after the write.
- Variable FX boxes draw every tile variable and save and start like on Habbo. Boss bars and the reference editor save like on Habbo.

### WIRED temporary furni
- Place Temporary Furni needs a Builders Club template that is still in the room. Copies from one firing arrive together.
- Wall furni can be used as temporary furni, with their position saved.

## Volt 3.5.0 and Volt Renderer 2.1.0

### New
- The cursed dragon adoption window and the new-feature promo bars.
- The avatar editor shows the pets tab and lists avatar collectibles, like on AIR.
- Daily task rewards are drawn by their reward type.
- The client reads the room data the server sends when the room opens, and no longer asks for it.
- Rooms with 2000 bots in different outfits and lots of chat stay smooth.

### Look like on AIR
- The chat style selector and chat bubbles match AIR. Bubbles stack with their pointer.
- The progression and Me menus match AIR and sit centred over their icon.
- The Builders Club warehouse window, the club gifts page and the catalogue header match AIR.
- The hotel view fills the screen behind the toolbar.
- The camera Edit button fits its label, prompt quests show their frame and the friend bar icon is no longer squeezed.
- Texts with `\n` show a line break, like on AIR.

### WIRED editor
- The area selectors and the neighbourhood grid look like on AIR.
- The hand item list adds carried hand items. Users In Group refreshes its group list. The selector editors have all their texts.
- Teleport to Room can pick any furni, and the server checks it.
- Wired errors show as a bubble with Habbo's text.

### Fixes
- Buy more HC opens the HC catalogue page. The football gate editor opens on the gate's saved look. Wall items are centred in the inventory preview.
- Builders Club furni draw like on AIR, with their colour palettes and their own infostand colour.
- Room background editing needs the branding permission.
- Furni animations restart on each state change, like on AIR.
- A room stays on screen when its data arrives right after login.

## Installer 1.3.0

- **New:** The setup guide shows how to get a Cloudflare Origin CA certificate, install it in nginx or IIS and turn on Cloudflare "Full (strict)". Before, it suggested a self-signed certificate.
- There are two guides. The simple guide is the default. Use `--guide-mode advanced` (Linux) or `-GuideMode advanced` (Windows) for the advanced guide with a manual admin checklist.
